Systems Interconnection Manual

Throttle -> VTOL Motors / Pusher Motor
Hover throttle sets PWM -> ESC commutation -> Motor RPM and thrust.
Transition airspeed 15-17 m/s -> VTOL motors idle, pusher active -> Wing-borne lift.
Altitude -> Atmosphere -> All Systems
Altitude up (max 4000m ASL) -> rho down, T down -> Hover power up.
rho at 4000m = 0.819 kg/m3 -> Hover power derates ~15%.
Airspeed -> Drag -> Power Required
V up in cruise -> Parasite drag up -> Power required up.
V below stall (~12 m/s) -> Wing drop, FCS triggers back-transition.
Battery SOC -> Flight Time -> RTL Trigger
High hover power (4336W) -> Rapid SOC drain -> 6 min VTOL budget.
SOC below reserve margin -> Automatic RTL -> Back-transition + VTOL land.
Lost Link -> Safety Manager -> RTL
Telemetry dropout > timeout -> Continue autonomous mission -> Failsafe RTL if no recovery.
Geofence breach -> Automatic RTL or FTS parachute.
GNSS Jam -> EKF3 -> Navigation Drift
RTK fix lost / GNSS jammed -> EKF3 switches to dead reckoning.
Position error grows ~1-3 m/s -> Geofence accuracy degrades.
Power Bus -> All Electrical Loads
Main battery fault -> BMS disconnect -> Backup battery -> FC survival.
Bus isolation -> Motor transients blocked from payload.
Mission Phase -> Payload -> Data Rate
Cruise survey phase -> LiDAR + RGB + thermal streaming -> High data rate to companion.
BLOS / no link -> Store onboard NVMe -> Offload after landing.
