Systems Interconnection Manual

Throttle → Motors
Hover: PWM → ESC → VTOL RPM/thrust. Transition 15–17 m/s: VTOL idle, pusher takes over → wing-borne flight.
Altitude → Atmosphere
Density falls with altitude. At 4000 m ρ≈0.819 → hover power rises ~15%.
Airspeed → Drag → Power
Cruise V↑ → parasite drag↑ → power required↑. Below stall (~12 m/s) → back-transition.
Battery SOC → RTL
Hover ~4336 W drains fast. Below reserve → automatic RTL + VTOL landing.
Lost Link → Failsafe
Timeout → continue mission then RTL. Geofence breach → RTL or parachute.
GNSS Jam → EKF3
RTK lost → dead reckoning. Position error grows; geofence accuracy degrades.
Power Bus Isolation
Main fault → BMS cut → backup keeps FC alive. Motor bus isolated from payload.
Mission Phase → Payload
Cruise survey streams LiDAR/RGB/thermal. No link → store on NVMe, offload after landing.
